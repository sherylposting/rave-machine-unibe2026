# Individual Lessons Learned - Sheryl Lin

### What were the most challenging bits of the course including project?
I really enjoyed this course - I am a Bioinformatics M.Sc and decided to take this as an elective, because although my program teaches us how to code, I never felt like they explained the larger context behind what the computer and systems were doing. I felt this course was like a good "cheese platter" of many underlying computer science concepts I missed, such as data structures, memory management, pointers, and generally being a more specific coder. As a result, it was quite fast-paced for me and I did not get to dive as deep into many concepts as I would've liked, but ultimately the purpose of the course as a taster was fulfilled for me. I am looking forward to learning Cython / C integrations in Python as I've heard it is useful in bioinformatics for speeding up bottleneck tasks which handle large datasets.

The most difficult concept for me was understanding the structure of function calls and system calls, stack vs heap, stack segment vs data segment vs text segment, CPU register and its pointers. Also, because our websensor concept was simple and lightweight to begin with, I do not feel I was forced to consider memory management in our project, so I did not really utilize dynamic memory allocation, combining bytes or bitwise filtering like I would have liked to in order to fully grasp these concepts. I would have liked to spend more time on these concepts and learn more about ex. different kinds of data buffers.

The project was definitely the most difficult (and most valuable) part of the course because it was highly independent, and none of it was content that I knew before. 

### Any never seen concepts learned?
I learned A LOT about how HTTP communication works. It was my first time building an HTML / Javascript web app. I have never made any sort of graphical interface or app before, so it was cool to finally understand what an "app" even is in general, and the different components that can make up the frontend and backend. I gained a decent understanding of server-client relationships, REST API and HTTP protocols. Learning how to set up an web sensor is actually something I could apply in the lab in the future, because it could be useful for remotely tracking or assisting with microscopy and other experiments.
